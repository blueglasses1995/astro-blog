# /document-knowledge Command

プロジェクト知識を適切なドキュメントファイルに格納するためのコマンドです。

## 使用方法

```
/document-knowledge [情報の内容]
```

## 説明

このコマンドは、ユーザーが提供した情報を分析し、適切なドキュメントファイルに整理・要約して格納します。

**このコマンドは`document-knowledge`スキルを使用してサブエージェントを起動し、実際の処理はサブエージェントが行います。**

## 実行フロー

1. ユーザーから情報を受け取る
2. `.claude/skills/document-knowledge.md`スキルを読み込む
3. サブエージェントを起動し、スキルの指示に従って処理を実行
4. サブエージェントが情報を分類・要約・格納
5. 結果を報告

## 使用例

### ADRの作成
```
/document-knowledge Astroを採用した理由は、SSGが必要でReactとの統合が重要だったから。Next.jsやGatsbyも検討したが、パフォーマンスと開発体験のバランスが良かった。トレードオフとして、動的コンテンツの制限がある。
```

### 用語集の追加
```
/document-knowledge このプロジェクトでは「ブログ記事」のことを「Post」と呼び、「Blog」は記事の集合を表す。変数名はpost、postId、postSlugを使用する。
```

### ビジネスルールの追加
```
/document-knowledge ブログ記事は公開後30分以内であればキャンセル可能。VIPユーザーは無料配送が適用される。
```

### エラーハンドリング戦略の追加
```
/document-knowledge ネットワークエラーは3回リトライし、認証エラーは即座にログアウトする。エラーログはDatadogに送信する。
```

## サブエージェントへの指示

このコマンドを実行する際は、以下のようにサブエージェントに指示してください：

```
`.claude/skills/document-knowledge.md`スキルを読み込み、ユーザーが提供した情報を分析し、適切なドキュメントファイルに整理・要約して格納してください。

提供された情報: [ユーザーが入力した情報]

スキルの指示に従って：
1. 情報の種類を判断
2. 適切なディレクトリ・ファイルを選択
3. 既存内容を確認
4. 情報を簡潔に整理・要約（100行以下）
5. フロントマター（メタデータ）を自動追加
6. ファイルを作成・更新
7. .serena/memories/にシンボリックリンクを作成（存在する場合）
8. ドキュメントインデックスを自動更新（npm run docs:index）
9. 結果を報告
```

## 注意事項

- 情報が不十分な場合は、ユーザーに追加情報を求める
- ADRの場合は、既存のADR番号を確認してから新しい番号を割り当てる
- ファイルが100行を超える場合は、分割を検討する
- 既存のADRファイルを編集する場合は、必ずユーザーに確認を求める
