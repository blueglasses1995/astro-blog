# /document-knowledge Command

プロジェクト知識を適切なドキュメントファイルに格納するコマンドです。

## 使用方法

```
/document-knowledge [情報の内容]
```

## 説明

ユーザーが提供した情報を分析し、適切なドキュメントファイルに整理・要約して格納します。

## 実行フロー

1. ユーザーから情報を受け取る
2. `document-knowledge`スキルを読み込む
3. 情報を分類・要約・格納
4. 結果を報告

## 使用例

### ADRの作成
```
/document-knowledge Astroを採用した理由は、SSGが必要でReactとの統合が重要だったから。
```

### 用語集の追加
```
/document-knowledge このプロジェクトでは「ブログ記事」のことを「Post」と呼ぶ。
```

### ビジネスルールの追加
```
/document-knowledge ブログ記事は公開後30分以内であればキャンセル可能。
```

## 注意事項

- 情報が不十分な場合は追加情報を求める
- ADRは既存の番号を確認してから新しい番号を割り当てる
- ファイルが100行を超える場合は分割を検討
