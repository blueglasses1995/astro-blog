# Document Knowledge Skill

ユーザーが提供した情報を整理・要約し、適切なドキュメントファイルに格納します。

## 行数制限（厳守）

| ファイル種類 | 最大行数 |
|-------------|---------|
| ADR | **50行以下** |
| その他 | 100行以下 |

## ディレクトリ構造

- `docs/adr/` - ADR（イミュータブル、50行以下）
- `docs/domain/` - ドメイン知識（ミュータブル）
- `docs/security/` - セキュリティ関連
- `docs/operations/` - 運用関連
- `docs/development/` - 開発関連
- `docs/integration/` - 統合関連

## ADR形式（50行以下厳守）

```markdown
---
title: "[タイトル]"
category: "adr"
immutable: true
tags: ["tag1"]
---

# ADR-XXXX: [タイトル]

## 決定
[簡潔に]

## ルール
[箇条書き]

## 理由
[箇条書き]

## トレードオフ
**利点**: [利点]
**制限**: [制限]
```

## 処理フロー

1. 情報を受領
2. 種類を判断
3. **ADRは50行以下、その他は100行以下**に要約
4. ファイル作成・更新
5. シンボリックリンク作成（.serena/memories/存在時）
6. インデックス更新

## 注意

- ADRは一度作成したら変更しない
- 冗長な説明は徹底的に排除
- 重複情報は統合
